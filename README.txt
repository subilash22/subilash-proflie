SUBILASH PERSONAL WEBSITE

Files:
- index.html: your website homepage
- assets/profile.jpg: the selected profile photo

Publish with GitHub Pages:
1. Create a new public GitHub repository (for example: subilash-profile).
2. Upload index.html and the assets folder, keeping the same folder structure.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. After GitHub gives you the website URL, open it and check the page.

Google indexing:
1. Open Google Search Console: https://search.google.com/search-console
2. Add your published website URL as a URL-prefix property and verify ownership.
3. Use URL Inspection to request indexing of the homepage.
Google indexing is not instant or guaranteed. It can take days or longer.
