SUBILASH — PERSONAL WEBSITE

Files:
- index.html: homepage with the 3-second black-hole opening
- about.html: About page
- photography.html: your supplied photographs, with click-to-expand lightbox
- projects.html: projects page
- contact.html: Instagram, GitHub and email
- assets/: CSS, JavaScript, black-hole intro image, favicon and optimized photographs

HOW TO PREVIEW:
Open index.html in a browser. Internet is only needed for Google Fonts; the website itself works without a framework.

HOW TO PUBLISH ON GITHUB PAGES:
1. Extract this ZIP.
2. Upload all files and folders inside this folder to the root of your GitHub repository.
3. Commit the changes. Keep the assets folder in the same location.
4. Open your GitHub Pages website.

NOTES:
- The black-hole intro runs for 3 seconds once per browser tab session, then does not repeat when navigating between pages.
- Photos are only shown on the dedicated Photography page.
- The contact page currently uses vertexstudio808@gmail.com, the email previously shared for your work. Change it in contact.html if you want a different personal Gmail.
