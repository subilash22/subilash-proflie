SUBI — 3D PERSONAL PORTFOLIO

Files:
- index.html
- style.css
- script.js
- assets/snow-trip.webp
- assets/portrait.webp

Preview:
Open index.html in a browser.

Publish on GitHub Pages:
1. Extract this ZIP.
2. Open your existing GitHub repository.
3. Replace the old website files with these files, keeping the assets folder.
4. Commit the changes.
5. GitHub Pages will publish the update.

The site is responsive and uses a CSS-built animated 3D hero object (no heavy 3D library).
Google Fonts require an internet connection; the rest of the layout works without external libraries.
